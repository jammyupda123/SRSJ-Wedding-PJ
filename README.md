# 결혼 준비 트래커 (PWA) 설치 가이드

설정 전에도 `index.html`을 호스팅만 하면 "이 기기에만 저장" 모드로 동작해요.
두 사람이 같이 쓰려면 아래 1~5번을 한 번만 하면 됩니다. (모두 무료 플랜)

## 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com → **프로젝트 추가** (Google Analytics는 꺼도 돼요)
2. 프로젝트 개요 → **웹 앱(</>) 추가** → 앱 닉네임 입력 → 나오는 `firebaseConfig` 값 복사

## 2. 로그인 방식 켜기
**빌드 → Authentication → 시작하기 → 로그인 방법 → 익명 → 사용 설정**

## 3. 데이터베이스 만들기
1. **빌드 → Firestore Database → 데이터베이스 만들기** (위치: `asia-northeast3` 서울, 프로덕션 모드)
2. **규칙** 탭에 `firestore.rules` 내용을 붙여넣고 **게시**

## 4. 설정 파일 채우기
`firebase-config.js`를 열어서
- `apiKey`, `authDomain`, `projectId`, `appId`에 1번에서 복사한 값을 넣고
- `coupleCode`를 우리만 아는 긴 영문/숫자(20자 이상)로 바꿔요. (이 코드가 데이터 주소예요. 남에게 알려주지 마세요)

## 5. 인터넷에 올리기 (둘 중 하나)
- **Netlify Drop**: https://app.netlify.com/drop 에 이 폴더를 통째로 끌어다 놓기 → 주소(https) 생성
- **GitHub Pages**: 저장소에 파일 올리고 Settings → Pages 에서 켜기
※ 반드시 https 주소여야 앱 설치가 돼요.

## 6. 폰에 설치
- **아이폰**: Safari로 주소 열기 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 주소 열기 → 메뉴(⋮) → **앱 설치** (또는 홈 화면에 추가)

같은 주소를 소림님께 보내면 같은 데이터를 같이 볼 수 있어요.

## 7. 처음 한 번
요약 탭의 **시트 내용으로 초기 데이터 넣기** 버튼을 누르면 기존 시트 내용이 들어가요. (한 사람이 한 번만!)

## 참고
- 설정 전(로컬 모드)에 입력한 데이터는 그 기기에만 있고, Firebase 연결 후에는 보이지 않아요.
- 파일을 수정해서 다시 올리면 앱을 한 번 닫았다 열 때 새 버전이 반영돼요.
- 오프라인에서도 화면은 열리고, 수정 내용은 연결되면 자동으로 동기화돼요.
